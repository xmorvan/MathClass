## Description (français)

MathClass accompagne l'enseignant de mathématiques pendant l'heure de cours.

Les élèves résolvent les exercices à la main, au stylet, sur iPad, comme sur une feuille. MathClass transcrit leur raisonnement ligne par ligne, l'élève vérifie la transcription, puis chaque étape est corrigée : l'élève voit où son calcul a déraillé, et peut retenter l'exercice.

Pendant la séance, l'enseignant suit sa classe en direct depuis l'iPad ou le Mac : qui travaille sur quel exercice, qui a terminé, qui bloque. Sur Mac, il peut envoyer des exercices supplémentaires à un élève qui a fini en avance.

Après la séance, les statistiques montrent les compétences maîtrisées, les erreurs qui reviennent (erreur de signe, calcul, notation) et la progression de chaque élève, avec export PDF pour les entretiens.

Pour différencier : niveaux de 1 à 5, groupes d'élèves, exercices ciblés par élève ou par groupe, trois modes de séance (différenciation, niveaux progressifs, évaluation).

Pour créer les exercices : saisie directe en notation mathématique, ou photo d'un énoncé que MathClass transcrit.

Les élèves n'ont ni adresse e-mail ni mot de passe : ils rejoignent la classe avec un code ou un QR code. Chacun ne voit que son propre travail. Pas de publicité, pas de traceur.

Pour essayer : créez un compte enseignant, puis chargez la classe de démo depuis votre profil.

## Description (English)

MathClass supports maths teachers during the lesson.

Students solve exercises by hand with the Apple Pencil, as on paper. MathClass transcribes their reasoning line by line, the student checks the transcription, then every step is marked: the student sees where the calculation went wrong and can try again.

During the lesson, the teacher follows the class live from iPad or Mac: who is on which exercise, who has finished, who is stuck. On Mac, the teacher can send extra exercises to a student who finished early.

After the lesson, statistics show which skills are mastered, which mistakes keep coming back (sign errors, arithmetic, notation) and how each student is progressing, with PDF export.

Differentiation: levels 1 to 5, student groups, exercises targeted per student or per group, three lesson modes.

Students need no email address and no password: they join with a class code or QR code, and each one sees only their own work. No ads, no tracking.

To try it: create a teacher account, then load the demo class from your profile.

## Texte « À tester » (TestFlight)

Merci d'essayer MathClass. Créez un compte enseignant, ouvrez votre profil (icône en haut à droite, « Mon profil ») et touchez « Charger les données de démo ». Relevez le code de la classe de démo (écran Classes), déconnectez-vous, choisissez « Élève », saisissez ce code et choisissez un nom. Résolvez un exercice au stylet, vérifiez la transcription et lisez la correction. Revenez ensuite en enseignant pour voir la copie et les statistiques. Vos remarques : bouton « Envoyer un commentaire » de TestFlight, ou par e-mail à À COMPLÉTER.

## Informations pour la revue d'Apple

Compte de démonstration : créer un compte enseignant dédié (par exemple revue-apple@ À COMPLÉTER), charger la démo, et fournir e-mail et mot de passe dans App Store Connect.

Notes pour le réviseur (en anglais) :

MathClass is a classroom tool for maths teachers. Sign in with the demo teacher account provided. The profile screen (person icon at the top right, then "Mon profil") has "Charger les données de démo" (load demo data), which creates a class with students, exercises and an active assignment. The Classes screen shows the class code (MX-XXXX). To see the student side: sign out, choose "Élève" (student), enter the class code, pick any name, and solve an exercise with the Apple Pencil or a finger. Students have no personal accounts; they join a class with a code given by their teacher. Teachers can delete their account in the profile screen ("Supprimer mon compte"). The app is in French by default; the profile screen has a language switch to English.

## Confidentialité (étiquettes App Store)

Suivi publicitaire (tracking) : non.

Données collectées, toutes pour « Fonctionnalités de l'app », toutes liées à l'identité de l'utilisateur, aucune utilisée pour le suivi :

| Catégorie App Store | Détail |
|---|---|
| Coordonnées : nom | prénom et nom de l'enseignant ; prénom et nom des élèves saisis par l'enseignant |
| Coordonnées : adresse e-mail | compte enseignant |
| Contenu utilisateur : photos | photos d'énoncés d'exercices prises par l'enseignant |
| Contenu utilisateur : autre | copies manuscrites, transcriptions, résultats |
| Identifiants : identifiant d'utilisateur | identifiant de compte (enseignant, compte anonyme élève) |
| Utilisation : interactions avec le produit | temps passé par exercice, progression |

Non collecté : localisation, contacts, historique de navigation, diagnostics, données financières, données de santé.

Chiffrement : l'app n'utilise que le chiffrement standard (HTTPS) ; la clé ITSAppUsesNonExemptEncryption est à NO dans le projet, Apple ne pose donc plus la question à chaque envoi.
